## 当前事实

- 当前引擎支持范围为 macOS Apple Silicon；其它平台能力不可用，不宣称跨平台支持。
- 超分源码、媒体边界、任务生命周期和真实模型短片回归已有记录。自动化/真实模型证据及具体限制以[实施与验证记录](./视频超分验证记录.md)为准。
- 隔离 macOS 桌面短片处理已成功；打开结果/导航、取消按钮交互、10 分钟上限压力、发行依赖再分发审查、签名发行资源及实际安装包离线验收仍未完成。逐步执行项以[测试与构建前检查指南](./视频超分测试指南.md)为准。
