# mediaGrab 路线图

路线图按“先完成可验收的 P0，再补稳定性和桌面发行能力”的顺序推进。旧的 M0/M1 只代表 B 站实验链路，不再作为产品版本号。

| 阶段 | 目标 | 状态 |
| --- | --- | --- |
| A0 | 产品重启：命名、领域模型、文档和 UI 基线 | 已完成 |
| A1 | 通用解析契约 + B 站 adapter + 下载任务闭环 | P0 收口中 |
| A2 | 抖音、小红书 adapter 与统一错误/权限模型 | 适配器已接入，真实验收中 |
| D1 | Tauri 桌面壳、三端开发运行与文件能力 | 壳与发行准备管线已实现，平台验收中 |
| D2 | 完成桌面运行时集成与三端验证 | 核心集成、身份握手与请求边界已有离线验证，真实安装验收待完成 |
| D3 | macOS/Windows/Linux 打包、签名、升级和发布 | CI 构建及安装后自动烟测已配置，需在对应 runner 实跑；签名、升级待完成 |

## 1.0 完成定义

三端安装包可在无用户预装 Node 的环境下启动；三平台核心功能真实可用；任务支持重启后恢复或明确失败；UI 不暴露内部平台实现细节；发行包包含或能可靠准备必要运行时并完成签名和安装验证。
