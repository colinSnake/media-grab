# mediaGrab 路线图

路线图按“先统一产品边界，再接入桌面和更多平台”的顺序推进。旧的 M0/M1 只代表 B 站实验链路，不再作为产品版本号。

| 阶段 | 目标 | 状态 |
| --- | --- | --- |
| A0 | 产品重启：命名、领域模型、文档和 UI 基线 | 已完成 |
| A1 | 通用解析契约 + B 站 adapter + 下载任务闭环 | 进行中 |
| A2 | 抖音、小红书 adapter 与统一错误/权限模型 | 进行中 |
| D1 | Tauri 桌面壳、三端开发运行与文件能力 | 进行中 |
| D2 | Rust core 接管下载、任务恢复和 FFmpeg | 计划 |
| D3 | macOS/Windows/Linux 打包、签名、升级和发布 | 计划 |

## 完成定义

产品达到 1.0 的条件：三端安装包都能在无 Node 环境下启动；B 站、抖音、小红书均能完成至少一个公开内容的解析和下载；任务在重启后可恢复或明确失败；UI 不暴露内部平台实现细节；所有 CI 测试不触网。
