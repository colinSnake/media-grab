| 项目 | 内容 |
| --- | --- |
| 文档版本 | v1.1 |
| 更新日期 | 2026-10-26 |

## 1. 产品定义

**一句话**：mediaGrab 是一个本地媒体工作台，把多平台链接转换成可选择、可追踪、可管理的本地视频或音频文件。

产品以完整流程为中心：输入链接、识别来源、展示可用资源、创建任务、观察进度、管理文件。首版不追求平台数量，而追求核心链路真实可用、失败可解释、文件不丢失。

## 2. 功能裁决

### 2.1 首版必须保留（P0）

1. **链接输入与来源识别**：支持输入或粘贴 B 站、抖音、小红书链接；不支持来源必须明确提示。
2. **媒体详情**：至少展示标题、作者、封面、时长、平台和可选资源；B 站多 P 必须能选择目标分 P。
3. **权限与能力说明**：创建任务前明确显示可用项、需要登录/大会员、缺少 FFmpeg/yt-dlp 或平台暂不支持等原因，不静默隐藏全部原因。
4. **输出选择**：视频+音频、仅视频、仅音频；音频支持 m4a 和 mp3，并正确提示 FFmpeg 依赖。
5. **任务闭环**：创建、排队、阶段状态、进度、速度、取消、失败重试；任务和设置写入本地持久化存储。
6. **安全落盘**：临时文件隔离，成功后再移动到目标目录；取消或失败不能留下可被误认为成功的半成品。
7. **保存目录**：默认使用系统 Downloads 下的 `mediaGrab` 目录，用户可修改并在重启后保留。
8. **桌面开发闭环**：Tauri 窗口能启动前端和本地核心；首版发布前不要求完整托盘、通知和自动更新。
9. **基础可用性**：1280px 桌面窗口、窄窗口和高 DPI 下不重叠、不溢出；日志和 UI 不泄露 Cookie、令牌或内部签名参数。

### 2.2 首版明确不作为阻塞项（P1）

- 拖拽链接文本。
- 批量粘贴和多任务并发配置界面。
- 断点续传、应用重启后继续下载、链接过期后自动重新取流。
- 失败自动重试策略。
- 系统通知、托盘常驻、打开文件夹、复制文件路径。
- 历史记录按平台/状态筛选和收藏。
- 小红书图文/图片资源；首版先完成视频资源闭环。
- 暂停/继续任务；首版只保证取消和重试。

### 2.3 后续扩展（P2）

- 更多平台适配器。
- 字幕、封面、章节和元数据导出。
- 播放列表与频道批量任务。
- 可选登录态和平台账号能力；登录不是基础功能前提。
- 三端安装包签名、自动更新、回滚和崩溃诊断。

### 2.4 明确不做

不做账号池、共享凭据、绕过会员或区域限制、破解 DRM、去水印、公网 SaaS、多用户权限系统和未经授权的批量抓取。所有平台能力以用户权限、公开能力和服务条款允许的范围为边界。

## 4. 首版核心流程

```text
输入或粘贴链接
  -> 平台识别与归一化
  -> 获取详情、分集和资源候选
  -> 展示可用项及权限/依赖原因
  -> 选择分集、资源和产物类型
  -> 创建本地任务
  -> 下载视频流 / 音频流
  -> 合并、remux 或转码
  -> 原子移动到目标目录
  -> 任务完成或给出可重试错误
```

任一阶段失败都必须保留可诊断的错误类别和用户可读文案。任务不能因为 UI 重新加载而丢失；取消必须中止处理并清理临时文件。

## 5. UI 信息架构

### 工作台

首屏只围绕“输入链接并解析”。展示支持的平台、核心服务状态和最近任务，不展示 WBI、数据库路径、签名参数等内部诊断信息。

### 解析结果

展示封面、来源、标题、作者、时长和资源候选。资源项至少显示产物类型、分辨率/音质、编码（如来源提供）和访问限制；不可用项保留原因。B 站多 P 必须提供分 P 选择。

### 任务中心

按进行中、已完成、失败/需重试分组。每项显示阶段、进度、速度、目标文件名和错误文案，并提供取消、重试、删除历史记录。暂停、通知、打开目录和复制路径属于 P1。

### 设置

P0 只展示实际生效的配置：下载目录、默认产物、音频格式、FFmpeg 状态、yt-dlp 状态和必要的平台登录状态。平台 Cookie 在设置中按 B站、抖音、小红书、YouTube 分开保存；默认不展示账号详情，B站多账号可按需展开管理。保存成功后 textarea 在当前会话保留输入，重启后不回显明文但加密凭据仍可用；除手动清除和 B站明确验证为未登录外，不凭一次解析失败自动清除 Cookie。并发数、日志开关等字段只有在真正生效后才展示为可配置项。

下载目录、yt-dlp 路径和默认输出各自于失焦时保存，不依赖弹窗底部的统一保存按钮；平台「保存 / 清空」仅作用于该平台 Cookie。若单项自动保存失败，应保留输入值并展示错误提示。

- [ ] 新安装、无账号、无历史数据时，用户可以直接输入或粘贴 B 站链接并进入解析结果。
- [x] B 站有/无 Cookie 均有可访问样本完成下载，最终文件由用户核对（2026-10-26）；样本链接与模式尚待记录。
- [x] 抖音无 Cookie 可访问样本已完成下载和文件核验（2026-10-26）；样本链接、资源选项与模式尚待记录，受限样本另行验收。
- [x] 小红书至少一个公开视频完成真实解析和下载；2026-10-20 已记录公开视频样本，2026-10-21 已记录登录态 1080P 文件落盘。
- [ ] 未安装 yt-dlp 时给出明确提示，并用对应环境完成验收。
- [ ] B 站多 P 可以选择目标分 P，不会默认下载错误分 P。
- [ ] 用户在创建任务前能知道当前选项是否需要登录、大会员或额外组件。
- [ ] 下载、合并、转码均能取消；取消后不留下伪装成成功文件的半成品。
- [ ] 任务和设置重启后仍存在；未完成任务显示为“可重试”或“可恢复”，不能伪装成成功。
- [ ] 默认目录为系统 Downloads 下的 `mediaGrab`，并支持用户修改。
- [ ] 任务中心显示阶段、进度和速度；未知总大小时显示不确定进度，不显示虚假百分比。
- [ ] 没有适配器或缺少依赖的链接得到明确错误，而不是通用网络错误。
- [ ] 1280px、窄窗口和高 DPI 下无内容重叠或按钮溢出。
- [ ] 类型检查、自动化测试和构建通过；CI 测试不依赖真实平台网络。

## 8. 工程与合规边界

- 桌面发行版不得要求用户手动安装 Node；发行包必须包含 Node core、FFmpeg 和 yt-dlp。仓库已有随包准备与验证管线，实际跨平台产物仍须按验收标准验证。
- 本地核心默认只监听回环地址；如启用访问令牌，API 必须校验令牌。
- 除用户主动粘贴在设置页且仅保留于当前会话的 Cookie 外，已保存的 Cookie、令牌、签名参数和完整敏感查询串不得回传 UI，也不得写入任务记录或普通日志。
- 只下载用户有权访问和保存的内容，并遵守各平台服务条款与版权法规。
