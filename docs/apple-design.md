# MediaGrab 的 Apple 风格设计摘要

本文把 Apple Human Interface Guidelines（HIG）中的通用原则转译为 MediaGrab 的 Web 与 macOS 桌面界面约定。它不是对 Apple 原生控件外观的逐像素复刻；MediaGrab 保留自己的品牌、跨平台一致性和下载工作台的信息密度。

## 核心原则

### 让内容和任务优先

MediaGrab 是高频使用的下载工作台。界面应帮助用户输入链接、识别来源、选择资源、跟踪任务和处理结果。装饰不能压过这些动作；普通面板保持安静，颜色用于建立层级、表达交互或传递状态。

### 用颜色表达稳定含义

- 产品交互强调统一使用蓝色。蓝色表示可交互的强调或当前选择，不表示成功、失败等任务结果。
- 成功、错误、警告分别使用绿色、红色、橙色语义色，并同时配合图标或文字，不能只靠颜色传达状态。
- 平台品牌色仅用于平台 Logo、来源标记等身份识别，不用于通用按钮、普通标题或大面积背景。
- 每个组件按角色消费颜色，例如 `--panel`、`--text-strong`、`--icon-accent`、`--control-selected`。不要在组件规则中复制另一套主题颜色。

### 适配浅色和深色外观

浅色和深色主题提供相同的语义 token，但分别定义具体颜色。背景层级、次要文字、占位符、边框、选中态和状态色都必须在两种主题中检查。不要通过给整个组件降低透明度来制造层级；这会让对比度随底色变化。

### 强调操作要有节制

一个视图通常只应有一到两个高强调的主要动作。MediaGrab 保留紫蓝渐变作为品牌表达，避免把渐变扩散到每一个次要按钮和容器；次要动作采用中性或轻量背景。工具栏图标按钮保持简洁但具有明确 hover、focus 和 disabled 状态。并列选项使用一致的尺寸，通过选中样式而不是尺寸差异表明当前值。

### 保持一致、可辨认的形状

圆角随元素层级变化：主面板和弹窗使用较大的圆角；输入框、按钮、任务行和选择项使用中等圆角；小图标容器使用较小圆角。相关组件保持一致，不把所有元素都做成胶囊，也不嵌套卡片。

## MediaGrab 当前控件约定

- 品牌仍使用现有紫蓝渐变，不把 Apple 风格误解为必须采用单色蓝或复制系统色板。
- 主要面板与弹窗采用约 `12px` 圆角，保持大面积容器柔和但不呈胶囊形。
- 输入框和主按钮采用约 `10px` 圆角；任务行、选项按钮和设置操作采用约 `8px` 圆角。
- 图标容器、徽标和紧凑型操作保留更小圆角，以形成清楚的层级。
- 同类控件的默认、悬停、选中和聚焦状态沿用同一外轮廓，不因状态跳变尺寸。
- 修改圆角时同步检查 `overflow: hidden`、焦点环和移动端布局，避免裁切或内容位移。

## 控件规则

- 输入框有稳定的边界、可读的占位符和清楚的焦点环；焦点不能只靠颜色变化表达。
- 主按钮背景承担强调，按钮文字保持高对比；同一组按钮高度和形状一致。
- 选择、分段控件和筛选器使用统一的选中态。非选中选项仍需可读，不靠过度淡化区分。
- 图标按钮应使用清晰、熟悉的图形，并提供可访问名称、hover 提示和键盘焦点状态。
- 平台徽标、视频封面和媒体预览属于内容识别层，可以保留必要的品牌色和图片覆盖色，不应污染全局控件色板。

## 可访问性检查

- 常规文字与背景的对比度目标至少为 4.5:1；大号文字目标至少为 3:1。关键控件边界和焦点指示也要在两种外观下可见。
- 颜色不是唯一状态线索。任务状态同时提供图标、文字或明确标签。
- 浅色和深色外观分别检查错误、成功、等待、选中、悬停、禁用和键盘焦点状态。
- 动画提供减少动态效果的降级；动画不得成为理解状态或完成操作的必要条件。

## 参考

- Apple Human Interface Guidelines, [Color](https://developer.apple.com/design/human-interface-guidelines/color)：克制并一致地使用颜色，为浅色、深色和辅助功能情境检查自定义颜色，避免只靠颜色表达信息。
- Apple Human Interface Guidelines, [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)：通过样式、内容和角色表达按钮用途，限制突出按钮数量，并保持同组按钮的尺寸与形状一致。
- Apple Human Interface Guidelines, [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)：关注文本和背景对比度，确保信息不只通过颜色传达。
