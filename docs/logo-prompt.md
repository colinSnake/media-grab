# MediaGrab Logo 生成提示词

## 设计目标

为跨平台桌面媒体下载与解析应用 **MediaGrab** 设计一套简洁、现代、专业的品牌 Logo。产品支持 B 站、抖音、小红书等平台的视频下载、媒体解析和音频提取，后续会扩展更多来源。Logo 需要同时适合 macOS Dock、Windows 开始菜单、Linux 应用菜单、桌面应用窗口左上角以及深色 UI 侧栏。

## 中文主提示词

```text
为跨平台桌面应用“MediaGrab”设计一个现代、专业、简洁的应用 Logo，主题是“媒体内容解析、整理和保存”。使用抽象的媒体卡片与播放窗口作为核心图形：一张略微倾斜的圆角媒体卡片，卡片中以左右分区的方式呈现一个简洁的播放三角形和一组音频波形竖线，播放符号在左、波形在右，两者之间必须留有明显空隙，任何尺寸下都不得相交、重叠或粘连；不要把播放符号叠在波形上，也不要使用下载箭头。图形要有独立识别性，不要依赖文字。

整体采用紫色到蓝色的高级渐变，主色为电光紫、靛蓝、清透蓝，渐变平滑但不过度炫光；深色背景上要有良好的对比度。图标外形为圆角方形，使用单一连续的渐变底面，不要添加黑色或深色外描边、暗色外框、投影边框或第二层底板；角落以透明方式收边。媒体卡片与底面保持柔和区分，适度使用半透明层次和柔和阴影，具有轻微的科技感和桌面软件质感。构图居中、留白充足、边缘清晰，缩小到 16 像素时播放符号与波形仍清楚分离，放大到 1024 像素时边缘仍然干净。

品牌气质：可靠、快速、克制、专业、跨平台、媒体工作台。视觉风格参考高品质生产力软件图标，不要做成视频网站 Logo，不要出现具体平台的品牌标志，不要使用 B 站、抖音、小红书的 Logo，不要出现复杂场景或人物。

输出一个透明背景的正方形应用图标，图形占画布约 78% 到 84%，四周保留安全边距。输出 SVG 或高分辨率 PNG，尺寸至少 1024×1024，适合生成 macOS、Windows、Linux 桌面应用图标。
```

## 推荐变体

可以基于主提示词分别生成以下三组方向，再选择一组继续迭代：

1. **媒体卡片版**：圆角卡片叠加播放窗口与音频波形，最适合作为默认应用图标，识别语义直接。
2. **字母抽象版**：将字母 `M` 的结构抽象成两条媒体轨道和一组波形，但不要直接显示字母，适合作为品牌符号。
3. **播放窗口版**：将播放三角、音频波形和媒体卡片融合成一个极简图形，适合强调“视频与音频解析”。

## 后处理要求

- 优先选择透明背景、正方形构图、单独主体的结果。
- 删除生成结果中的任何文字、平台标识、样机边框和背景纹理。
- 确保深色背景 `#101014` 和浅色背景上都清晰可见。
- 生成桌面图标前，保留一份原始透明 PNG，至少 `1024×1024`。
- 生成网页 Logo 时可以保留完整渐变；生成系统图标时避免过细的线条和过低的透明度。
- 应用侧栏建议使用 `32×32` 或 `40×40`；窗口图标和安装包图标使用 `512×512` 或更高分辨率。

## 当前仓库实现

仓库已内置一版不依赖外部图片的矢量 Logo：

- `apps/web/src/assets/mediagrab-logo.svg`
- `apps/desktop/src-tauri/icons/icon.png`

后续如果生成了更满意的图形，只需要用同一套安全边距和透明背景替换这两个资源，并重新执行桌面构建即可。
